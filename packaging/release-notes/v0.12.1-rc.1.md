## New

- **Downloads from this fork for all three desktops.** Windows installers and ZIPs, a universal Mac DMG, and Linux archives come with signed checksums. By @31780.
- **Updates stay on this fork.** Stable update checks use this repository and its own signing key. Test releases are downloaded manually. By @31780.

## Fixed

- **Updates require a publisher signature.** Missing or forged signatures stop an update before executable code is downloaded. By @31780.
- **Playback debug logs redact protocol details.** Verbose logs no longer include raw playback protocol messages that can contain credentials. By @31780.
- **Sign-in callbacks cannot hang indefinitely on an incomplete request.** Callback reads are bounded, and cancellation interrupts active connections. By @31780.
- **Patched TLS dependency.** Updated rustls to 0.23.45. By @31780.

## Known limitations

- Playback requires your own Spotify Premium account. First-time login can still wait on the shared Spotify app’s rate limit. Personal app setup is available in Settings after sign-in. See the [installation and login guide](https://github.com/31780/spotifast/blob/v0.12.1-rc.1/README.md#spotify-login).
- Windows and macOS may show an unidentified-publisher warning. These builds are not Authenticode-signed or Apple-notarized; release checksum signatures are separate.
- Linux archives require glibc 2.39 or newer. Windows ARM does not include MilkDrop.
- This fork shares upstream’s application identity and settings. Quit the existing app before replacing it.
